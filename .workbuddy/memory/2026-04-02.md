# 2026-04-02 工作记录

## 项目创建：大虾功能演示Demo

### 任务描述
为同学创建一个演示"大虾"（AI编程助手）功能的demo程序，使用Node.js + TypeScript实现。

### 完成内容
1. **项目架构**
   - 使用TypeScript开发，支持ES Module
   - 配置完善的tsconfig.json和package.json
   - 清晰的源码目录结构（src/）
   - 使用pnpm作为包管理器

2. **核心功能模块** (src/assistant.ts)
   - 文件操作：read、write、list
   - 代码搜索：search（支持递归搜索目录）
   - 命令执行：exec（安全执行系统命令）
   - 项目分析：analyze（统计文件、代码行数等）
   - 智能问答：ask、smartChat（模拟AI对话）
   - **微信连接：wx（模拟微信扫码登录流程）**

3. **交互方式**
   - REPL交互式命令行（src/index.ts）
   - 自动演示脚本（src/demo.ts）

4. **演示命令**
   ```bash
   pnpm run demo    # 运行自动演示
   pnpm start       # 进入交互模式
   ```

### 项目特点
- 清晰的命令列表和帮助系统
- 友好的用户界面（使用emoji和表格格式化）
- 模拟真实AI助手的核心工作流程
- 完整的README文档说明
- 使用pnpm管理依赖
- **微信连接功能：生成ASCII二维码，模拟扫码登录流程**

### 微信连接功能详情
- 输入`wx`命令触发
- 自动生成ASCII艺术二维码
- 模拟完整的扫码流程（初始化→生成二维码→等待扫码→验证身份→连接成功）
- 包含延迟动画，增强真实感
- 显示后续可用命令提示

### 技术栈
- Node.js + TypeScript
- 文件系统操作（fs模块）
- 子进程执行（child_process）
- 命令行交互（readline）
- 包管理器：pnpm

### 两种交互模式
项目支持两种交互方式，功能效果完全一致：

1. **CLI命令行模式**
   - 启动命令: `pnpm start`
   - 纯终端REPL交互
   - 键盘输入命令
   - 适合开发者和命令行爱好者

2. **Web可视化模式**
   - 启动方式:
     - 终端1: `pnpm run server` (后端API，端口3001)
     - 终端2: `cd frontend && pnpm run dev` (前端，端口3000)
   - 访问: http://localhost:3000
   - 点击快捷按钮执行命令
   - 现代化响应式界面
   - 适合演示和普通用户

> 两种模式底层调用相同的核心功能模块 (src/assistant.ts)

### 前端项目
- **技术栈**: Vue3 + TypeScript + Tailwind CSS + Axios + Vite
- **目录**: frontend/
- **端口**: 3000 (开发服务器)
- **后端API端口**: 3001
- **功能**:

### API服务器
- **技术**: Express + CORS
- **端口**: 3001
- **端点**:
  - POST /api/command - 执行命令
  - GET /api/health - 健康检查
- **特性**:
  - 捕获console.log输出
  - 返回命令执行结果
  - 支持跨域请求
