## 项目创建：大虾功能演示Demo

### 任务描述
为同学创建一个演示"大虾"（AI编程助手）功能的demo程序，使用Node.js + TypeScript实现。

### 完成内容
1. **项目架构**
   - 使用TypeScript开发，支持ES Module
   - 配置完善的tsconfig.json和package.json
   - 清晰的源码目录结构（src/）
   - 使用pnpm作为包管理器

2. **核心功能模块** (src/assistant.ts)
   - 文件操作：read、write、list
   - 代码搜索：search（支持递归搜索目录）
   - 命令执行：exec（安全执行系统命令）
   - 项目分析：analyze（统计文件、代码行数等）
   - 智能问答：ask、smartChat（模拟AI对话）
   - **微信连接：wx（模拟微信扫码登录流程）**

3. **交互方式**
   - REPL交互式命令行（src/index.ts）
   - 自动演示脚本（src/demo.ts）

4. **演示命令**
   ```bash
   pnpm run demo    # 运行自动演示
   pnpm start       # 进入交互模式
   ```

### 项目特点
- 清晰的命令列表和帮助系统
- 友好的用户界面（使用emoji和表格格式化）
- 模拟真实AI助手的核心工作流程
- 完整的README文档说明
- 使用pnpm管理依赖
- **微信连接功能：生成ASCII二维码，模拟扫码登录流程**

### 微信连接功能详情
- 输入`wx`命令触发
- 自动生成ASCII艺术二维码
- 模拟完整的扫码流程（初始化→生成二维码→等待扫码→验证身份→连接成功）
- 包含延迟动画，增强真实感
- 显示后续可用命令提示

### 技术栈
- Node.js + TypeScript
- 文件系统操作（fs模块）
- 子进程执行（child_process）
- 命令行交互（readline）
- 包管理器：pnpm
