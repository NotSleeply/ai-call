## CLI 加载动画优化

### 任务描述
CLI 命令执行响应太快不真实，需要添加加载等待动画。

### 完成内容

1. **旋转加载动画**
   - 随机等待时长：1-20 秒
   - 动画符号：`⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧ ⠇ ⠏` 循环
   - 显示格式：`⠹ 思考中... 5s`
   - 实时倒计时显示

2. **命令差异化提示**
   - weather → "获取天气"
   - news → "获取新闻"
   - email → "获取邮件"
   - wx → "连接微信"
   - analyze → "分析项目"
   - search → "搜索内容"
   - 其他命令 → "思考中"

3. **实现方式**
   - 在 `src/index.ts` 中添加 `showLoadingSpinner` 方法
   - 在 `handleCommand` 中每个命令执行前调用加载动画
   - 使用 `process.stdout.write` 实现原地更新
   - 特殊命令（history、new）不显示加载动画

### 效果
- CLI 执行命令时有真实的等待感
- 用户能看到实时倒计时和旋转动画
- 不同命令显示不同的加载提示
